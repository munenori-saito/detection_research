2. 各カメラの詳細と逆走検知への活用アプローチ

2.1 AI交通監視カメラ / トンネル監視カメラ（★本研究の主対象）特徴:AI（画像解析アルゴリズム）による自動認識を前提とした次世代型カメラ。画角が固定されており、車線（レーン）の定義や走行方向の基準座標（ROI）をあらかじめシステム側で固定設定できる。カメラ内部にAIプロセッサ（NVIDIA Jetson等）を備えたエッジAIモデルや、路側帯のエッジ計算機に接続される形態が多い。逆走検知へのアプローチ:YOLO ＋ MOT（マルチオブジェクトトラッキング） の直接適用に最も適している。車両を検出し、フレーム間での個体識別（ID割り振り）を行って移動ベクトル（進行方向）を維持・算出することで、リアルタイムに逆走車を検出可能。

2.2 道路監視CCTVカメラ（広域監視用）特徴:国土交通省やNEXCOなどの道路管制センターの「人間の監視員」が目視で現場を確認するためのカメラ。PTZ（パン・チルト・ズーム）機能を持ち、管制員の操作によってカメラの角度や倍率が動的に変化する。逆走検知へのアプローチ:カメラの角度が変わると背景や車線の座標基準が崩れるため、固定AIモデルでは誤検知が生じやすい。近年の研究では、カメラの回転・ズーム動作を自動検出して判定基準を動的に再学習・再校正するモデルや、オプティカルフロー（全体の動き解析）を組み合わせて対応する手法が提案されている。  

2.3 ナンバー認識カメラ / Nシステム / ETCカメラ（メタデータ連携用）特徴:通過車両のナンバープレート読取や車両識別を行う単機能・高精度カメラ。逆走検知へのアプローチ:映像単体での移動ベクトル判定ではなく、通過ログ（タイムスタンプ）の順序判定やメタデータ解析に活用する。本来「地点A（入口）➔ 地点B（出口）」の順で記録されるべき車両ID/ナンバーが「地点B ➔ 地点A」の順で記録された場合に逆走と判定する（NECのメタデータ解析技術の設計思想）。  正面を撮影するカメラに対して車両の「背面（リア）」が映り込んだ場合を逆走トリガーとするアプローチも可能。

2.4 オービス（速度違反取締装置）特徴:高精度カメラとドップラーレーダーまたはレーザーセンサーが統合された装置。逆走検知へのアプローチ:物理センサー（ミリ波レーダー等）によって物体の接近・遠ざかりの移動方向と速度を判定できるため、画像認識補正用の物理トリガーとして活用可能。
