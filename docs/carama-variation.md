# 🛣 道路監視カメラの種類と特徴（逆走検知システム視点）

本ドキュメントは、実社会の道路インフラに設置されている監視カメラの分類・特徴と、AIを用いた逆走検知（`rev-detect`）における活用・適用方法を整理したものである。

---

## 1. カメラ分類と主な役割一覧

| 分類 | 主な役割 | 画角・動作 | 1台で複数用途 | 主なセンサー・機能特徴 |
| :--- | :--- | :--- | :---: | :--- |
| **AI交通監視カメラ** | 車両検出・交通量計測・異常（逆走/停止）自動検知 | **固定画角** | ◎ | HD〜4K、暗所性能（赤外線/サーマル）、エッジAI処理対応 |
| **道路監視CCTV** | 渋滞・事故・道路状況の目視監視 | **PTZ**<br>(首振り・ズーム) | ◎ | HD〜4K、広角、夜間対応、遠隔操作 |
| **トンネル監視カメラ** | トンネル内の事故・停止・逆走・火災検知 | **固定画角** | ◎ | 暗所性能、広角、AI画像解析機能 |
| **ナンバー認識カメラ / Nシステム** | ナンバー読取・手配車両捜査 | **固定画角** | △ | 高速シャッター、望遠、赤外線照明 |
| **ETC関連カメラ** | ETCレーンでの車両確認・ナンバー撮影 | **固定画角** | ○ | ナンバー/車両撮影 ＋ ETC車載器通信 |
| **オービス** | 速度違反取調 | **固定画角** | △ | カメラ ＋ レーダー/レーザーセンサー |

## 2. 各カメラの詳細と逆走検知への活用アプローチ

### 2.1 AI交通監視カメラ / トンネル監視カメラ（★本研究の主対象）
* **特徴**: 
  * AI（画像解析アルゴリズム）による自動認識を前提とした次世代型カメラ。
  * 画角が固定されており、車線（レーン）の定義や走行方向の基準座標（ROI）をあらかじめシステム側で固定設定できる。
  * カメラ内部にAIプロセッサ（NVIDIA Jetson等）を備えたエッジAIモデルや、路側帯のエッジ計算機に接続される形態が多い。
* **逆走検知へのアプローチ**:
  * **`YOLO` ＋ `MOT（マルチオブジェクトトラッキング）`** の直接適用に最も適している。
  * 車両を検出し、フレーム間での個体識別（ID割り振り）を行って移動ベクトル（進行方向）を維持・算出することで、リアルタイムに逆走車を検出可能。

### 2.2 道路監視CCTVカメラ（広域監視用）
* **特徴**: 
  * 国土交通省やNEXCOなどの道路管制センターの「人間の監視員」が目視で現場を確認するためのカメラ。
  * PTZ（パン・チルト・ズーム）機能を持ち、管制員の操作によってカメラの角度や倍率が動的に変化する。
* **逆走検知へのアプローチ**:
  * カメラの角度が変わると背景や車線の座標基準が崩れるため、固定AIモデルでは誤検知が生じやすい。
  * 近年の研究では、カメラの回転・ズーム動作を自動検出して判定基準を動的に再学習・再校正するモデルや、オプティカルフロー（全体の動き解析）を組み合わせて対応する手法が提案されている[cite: 1]。

### 2.3 ナンバー認識カメラ / Nシステム / ETCカメラ（メタデータ連携用）
* **特徴**: 
  * 通過車両のナンバープレート読取や車両識別を行う単機能・高精度カメラ。
* **逆走検知へのアプローチ**:
  * 映像単体での移動ベクトル判定ではなく、**通過ログ（タイムスタンプ）の順序判定**や**メタデータ解析**に活用する。
  * 本来「地点A（入口）➔ 地点B（出口）」の順で記録されるべき車両ID/ナンバーが「地点B ➔ 地点A」の順で記録された場合に逆走と判定する（NECのメタデータ解析技術の設計思想）[cite: 1]。
  * 正面を撮影するカメラに対して車両の「背面（リア）」が映り込んだ場合を逆走トリガーとするアプローチも可能。

### 2.4 オービス（速度違反取締装置）
* **特徴**: 
  * 高精度カメラとドップラーレーダーまたはレーザーセンサーが統合された装置。
* **逆走検知へのアプローチ**:
  * 物理センサー（ミリ波レーダー等）によって物体の接近・遠ざかりの移動方向と速度を判定できるため、画像認識補正用の物理トリガーとして活用可能。

## 3. 本研究（`rev-detect`）における位置づけと展開ストーリー

1. **フェーズ 1（現在・プロトタイプ作成）**:
   * 実装および検証の第一歩として、画角が固定された **「AI交通監視カメラ」** を想定環境とする。
   * YOLOv8 による車両検出（Car, Truck等）とトラッキング機能（BYTETracker等）を組み合わせ、移動ベクトルから逆走を判定する単体カメラアルゴリズムを構築する。

2. **フェーズ 2（研究の発展・実用化検討）**:
   * 将来的な拡張として、PTZ動作用の自動補正機構を取り入れることで **「道路監視CCTV」** へ対応させる。
   * 検知した逆走車両の情報を **「ナンバー認識カメラ・ETC等のメタデータ基盤」** と連携させ、通過ログの特定や追跡を行う統合システムへの拡張を目指す[cite: 1]。
