| アプローチ（カテゴリ） | 具体的な手法名 | 内容・メカニズム |
|---|---|---|
| **1. モデル構造の効率化**<br>*(Architecture Design)* | **Depthwise Separable Conv** | 通常の畳み込みを「空間方向」と「チャネル方向」の2段階に分割し、計算量とパラメータ数を大幅に削減する。 |
| | **Reparameterization** | 学習時は複雑なマルチブランチ構造で精度を高め、推論時は数学的に単一の層（直列）に統合してメモリアクセスを高速化する。 |
| **2. モデル圧縮**<br>*(Model Compression)* | **量子化 (Quantization)** | 重みや中間出力のデータ型（32bit浮動小数点）を8bit整数（INT8）などに丸め、モデルサイズ縮小と演算速度向上を図る。 |
| | **枝刈り (Pruning)** | 精度への寄与が低いネットワーク内の重み（接続）やチャネルを削除し、計算リソースの消費を抑える。 |
| **3. 学習手法の工夫**<br>*(Training Strategies)* | **知識蒸留 (Knowledge Distillation)** | 高精度な巨大モデル（教師）の出力傾向や特徴マップを、軽量モデル（生徒）に模倣させて推論精度を底上げする。 |
| | **NAS (Neural Architecture Search)** | デバイスの制約（レイテンシや消費電力）を条件に含め、最適なネットワーク構造をアルゴリズムに自動探索させる。 |
| **4. ハードウェア最適化**<br>*(Runtime Optimization)* | **推論エンジンの活用** | 実行ハードウェア（Intel, NVIDIA, ARM等）に特化した専用コンパイラ（OpenVINO, TensorRT, NCNN等）を用いて推論を実行する。 |
| | **Layer Fusion (層の融合)** | 畳み込み層、正規化層、活性化関数などの連続する処理をメモリ上で1つの演算に結合し、データ転送の遅延を極小化する。 |
