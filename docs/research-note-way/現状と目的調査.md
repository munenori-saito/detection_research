# 日本における車両の逆走検知・予測・警報に関する研究動向まとめ

本資料は、日本国内における**車両の逆走検知・逆走予測・逆走警報**について、学術研究、公的資料、特許、商用システム、実証実験などを整理したものである。

日本の逆走研究は、論文だけで発展してきたというより、**NEXCOなどの道路会社、メーカー、大学、研究機関が実際の道路で技術を検証しながら発展してきた「実装主導型」の分野**である。

## 1. なぜ逆走検知が必要なのか

高速道路では、標識や路面表示、ラバーポールなどによる逆走防止対策が進められてきた。しかし、それでも逆走はなくなっていない。

2025年には高速道路で**297件の逆走事案**が確認され、2011年以降で最多となった。そのうち**64件が事故**につながっている。

逆走事故そのものは高速道路事故全体の約0.1％と少ないものの、**重大事故率は通常事故の約4倍、死亡事故率は約35倍**とされる。

また、2025年までにIC・JCT・SA・PAなどの基本的な逆走対策はほぼ整備されている。それでも逆走が発生していることから、今後は「逆走させない」だけでなく、

**予防 → 前兆検出 → 逆走検知 → 警報 → 管制対応**

という多層的な安全対策が必要になっている。

## 2. 現在使われている主な逆走検知技術

逆走検知技術は、大きく分けると次のような方式がある。

1. **ループ式車両検知器**  
   道路に設置された2つの誘導ループを車両が通過する順番から進行方向を判定する。既存設備を利用でき、雨・夜間などの影響を受けにくい。一方、渋滞や車線変更によって疑似的な逆走パターンが発生する場合がある。

2. **レーダー・LiDAR**  
   車両の距離、速度、移動方向などから逆走を判断する。画像を使わないため夜間や悪天候に比較的強い。IHIの3D LiDARシステムは2024年から名古屋高速で実運用されている。

3. **CCTV＋AI画像解析**  
   既設の道路監視カメラ映像から車両を検出・追跡し、移動方向によって逆走を判断する。既存CCTVを利用できるため、現在特に注目されている。ただし、夜間、逆光、雨雪、遮蔽、カメラ角度の変更などが課題となる。

4. **GNSS＋地図情報**  
   車両の位置や進行方向を道路地図と比較して逆走を判断する。道路側設備を必要としない一方、並走道路、立体交差、GPS誤差、マップマッチングの失敗による誤警報が問題になる。

5. **ETC2.0・Bluetooth・スマートフォン**  
   路側設備と車両・スマートフォンを連携させて逆走を判定・警告する。逆走車本人に直接警報できるメリットがあるが、対応車載器やアプリの普及率に左右される。

## 3. 現在特に注目されている「CCTV＋AI」

近年の中心的な技術は、**既設CCTVをAIで解析する方式**である。

NEXCOが2024～2025年に行った新しい逆走対策技術の公募では、固定CCTVによる逆走検知について、

**検知率90％以上、誤検知率10％未満**

が基本要件として示された。

さらに期待性能として、100％検知・0％誤検知や、検知から外部への情報送信までおおむね1分以内などが設定されている。

2025年には21提案中19提案が選定され、Dahua、東芝テリー、パナソニック コネクト、富士通、住友電工システムソリューションなど、多数の企業によるAI画像解析技術が実証対象となった。

ただし、2026年9月時点では各方式の十分な実道路での精度データはまだ限定的であり、**AIモデルや学習画像数、逆走車の学習サンプル数などがほとんど公開されていない**ことも研究上の課題となっている。

## 4. 実道路で高い評価を得ている例

公開されている中で特に詳細な評価が行われているのが、**住友電工のループ式逆走検知システム**である。

工事規制区間を利用した実車試験では、10～60km/hの順走・逆走条件で**100％の判別**を確認した。

さらに一般交通環境で、

**46日間・約5,500万台**

を対象に検証した結果、12件の逆走候補が検出されたが、すべて工事による車線規制に伴うものであり、交通管制情報と組み合わせることで警報を抑制できた。

また、118回・計55.7時間の渋滞でも誤った逆走通知は発生しなかった。

ただし、この期間には自然発生した本物の逆走がなかったため、**実際の逆走をどの程度検出できるのかを完全に証明した試験ではない**点には注意が必要である。

この研究から重要なのは、単純にAIやセンサだけで判断するのではなく、

**センサ情報＋交通状況＋工事情報**

を組み合わせることで誤報を減らせるという点である。

## 5. 「逆走検知」から「逆走予測」へ

これまでの技術の多くは、**すでに車が逆方向に走り始めた後に検知するもの**であった。

しかし近年は、逆走する前の行動を捉えようとする研究が始まっている。

2026年の大阪大学・あいおいニッセイ同和損保の研究では、約2年間のテレマティクスデータを使い、

**誤進路 → 躊躇 → 転回 → 逆走**

といった逆走に至る過程を分析している。

また、J-QuAD DYNAMICSの特許では、合流部に設置された道路標識などを車載カメラで認識し、その位置や移動方向から、**実際に逆走を開始する前に逆走しようとしている状態を判定する**考え方が示されている。

国土交通省の調査でも、2025年の逆走事案の約6割が「行き先を間違えたこと」などを契機としている。

そのため、逆走が始まってから検出するよりも、**ICや分岐で誤った進路を選択した段階で危険を検知すること**が重要になっている。

## 6. 現在の研究に残されている大きな課題

最大の問題は、**実際の逆走データが極端に少ないこと**である。

通常走行の映像は大量に集められるが、本物の逆走映像はほとんど存在しない。また、安全上の理由から高速道路上で大量の逆走を再現することも難しい。

そのため、今後は閉鎖道路での実車試験、過去映像、シミュレーション、合成映像などを組み合わせた共通データセットが必要になる。

さらに、単純な「Accuracy」だけでは性能を評価できない。

逆走のような非常に珍しい事象では、すべてを「正常」と判定しても99％以上のAccuracyになる可能性がある。

そのため今後は、

**Recall・Precision・100万台当たりの誤警報数・1000時間当たりの誤報数・検知までの時間・警報までの時間**

などを統一して評価する必要がある。

## 7. 今後重要になる研究方向

資料全体から見ると、日本の逆走対策は、

**標識・路面表示  
→ 専用センサ  
→ 既設CCTV＋AI  
→ 路車協調警報  
→ 逆走前兆予測**

という方向へ発展している。

特に今後重要なのは、単一のAIやセンサで「100％検知」を目指すことではない。

CCTV、ループ、レーダー、LiDAR、道路地図、工事情報、車載センサなどを組み合わせる**センサフュージョン**が重要になる。

例えば、

**CCTVで逆走候補を発見  
→ ループやレーダーで確認  
→ 工事・交通情報と照合  
→ 逆走車本人へ警告  
→ 周辺の順走車へ警告  
→ 交通管制センターへ通知**

という流れである。

さらに将来的には、逆走開始後ではなく、ICでの誤進路やUターンなどから「30秒以内に逆走する可能性」を推定し、**逆走が始まる前に警告するシステム**へ発展することが期待されている。

## まとめ

日本では逆走防止設備がほぼ全国的に整備されているにもかかわらず、逆走事案は依然として発生している。

そのため研究の中心は、単純な物理的防止策から、**AI・センサ・通信技術を利用した早期検知と警報**へ移っている。

特に現在は**既設CCTV＋AI**が実用化の中心となっているが、実逆走データの不足、誤報率の評価方法、悪天候や夜間への対応、検知から警報までの遅延などに課題が残る。

今後の重要な研究テーマは、単なる「逆走車の検出」ではなく、

**逆走前兆予測 → 早期警告 → 確定検知 → 順走車への警告 → 管制対応**

までを一つのシステムとして設計・評価することである。

特に、複数センサの融合、共通評価データセットの構築、そして**「逆走してから検知する」のではなく「逆走する前に予測する」技術**が、今後の研究の中心になると整理できる。
