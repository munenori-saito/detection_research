
# 熱赤外線カメラを用いた逆走検知に関する先行研究調査

## 1. 先行研究①：熱赤外線カメラによる車両検出・追跡

Bhadoriyaら（2022）は、熱赤外線カメラとレーダーを組み合わせた車両検出・追跡システムを開発した。

本研究では、**FLIR製の熱赤外線カメラ5台**を使用した。各カメラの画角は50°であり、画像を結合することで190°の広視野画像を生成している。使用したカメラは長波長赤外線（LWIR、波長8～14μm）を利用するもので、可視光の照明がない夜間でも車両の熱放射を捉えられる。

車両検出にはYOLOv3を使用し、熱画像に対応するよう入力を1チャンネルのグレースケール画像に変更して再学習した。その後、レーダーから取得した距離・相対速度の情報と組み合わせ、JPDAとMHTによる車両追跡を行った。

**JPDA（Joint Probabilistic Data Association）** は、新たな観測データがどの車両に対応するかを確率的に評価し、複数の観測結果を確率に応じて重み付けすることで追跡を行う手法である。各時刻で観測データを処理するため、比較的計算量を抑えやすい。

一方、**MHT（Multiple Hypothesis Tracking）** は、観測データと車両の対応関係について複数の仮説を保持し、その後の観測結果も利用して最も可能性の高い組み合わせを選択する手法である。複雑な状況でも追跡を維持しやすい反面、仮説の数が増加すると計算量が大きくなる。

実車実験では、夜間や強い逆光下でも車両の検出・追跡が可能であることを確認した。また、シミュレーションによる定量評価では、以下の結果が得られた。

| 追跡手法 | ID Precision | ID Recall |
|---|---:|---:|
| JPDA | 38.2% | 44.7% |
| MHT | 49.0% | 68.0% |

MHTはJPDAよりも高い追跡精度を示した。ただし、これらは車両の識別追跡精度であり、逆走検知そのものの精度ではない。

また、同方向に走行する車両は比較的安定して追跡できた一方、対向車両の追跡は不安定であり、追跡アルゴリズムや物体検出精度の改善が課題として挙げられた。

## 2. 先行研究②：米国アリゾナ州における逆走検知の実証実験

アリゾナ州交通局（ADOT）は、2018年1月から2019年12月まで、州間高速道路I-17の約24km区間において、熱赤外線カメラを用いた逆走検知システムの実証実験を行った。

本システムには、**FLIR製TrafiSenseシリーズの熱赤外線カメラを90台**使用した。これらは車両と周囲の熱放射の違いを利用して物体を捉える交通監視用カメラであり、夜間などの照明条件に左右されにくい特徴を持つ。なお、報告書には使用機種が記載されているものの、各機種の詳細な波長帯や解像度は示されていない。

逆走検知には、熱画像上に設定した「逆方向検知ゾーン（Inverse Detection Zone）」を使用した。車両が検知ゾーン内を通常の交通方向と反対に移動すると逆走として判定し、警告標識の点滅や管制センターへの通知を行う。また、既設CCTVを利用して逆走車両の位置を追跡する仕組みとなっている。

2年間の実証実験では、以下の成果が得られた。

| 評価項目 | 実証結果 |
|---|---|
| 逆走事象の検知件数 | 109件 |
| 夜間の検知件数 | 93件（約85%） |
| 本線進入前に方向修正した割合 | 約88% |
| 従来の911通報に対する先行時間 | 平均98秒 |

この結果から、熱赤外線カメラによる逆走検知は、夜間を含む実際の道路環境でも運用可能であり、従来の通報方式より早期に逆走事象を把握できることが示された。

一方、強風によるカメラの振動、歩行者、大型車両による遮蔽、鳥などが原因で誤検知が発生した。これらに対して、設置位置や検知ゾーンの調整、振動補正アルゴリズムの導入によって改善を図った。

ただし、逆走の見逃し件数や誤検知の総件数は公表されておらず、PrecisionやRecallによる定量的な精度評価はできない。また、雨や霧などの気象条件別の検知性能についても十分なデータは示されていない。

## 3. 考察・今後の研究課題

以上の調査から、熱赤外線カメラは夜間や逆光下での車両検出に有効であり、実際の高速道路における逆走検知にも利用されていることが確認できた。

一方で、対向車両の追跡性能、カメラの振動や遮蔽による誤検知などの課題が残されている。また、可視光CCTVと熱赤外線カメラを同一条件で比較した定量的な検知精度については、今回の資料から確認できなかった。

今後は、**可視光CCTVと熱赤外線カメラによる逆走検知の性能を比較し、夜間や悪天候における検知精度、誤検知率、処理速度、導入費用を定量的に評価すること**が重要である。
