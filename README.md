## git コマンド

## ギットのコマンドライン上で使用するコマンドをまとめたので参考にしてください

---

### 1. 日常の開発フロー（基本操作）

| 操作 | コマンド | 説明 |
| :--- | :--- | :--- |
| **最新コードの取得** | `git checkout main`<br>`git pull origin main` | 最新の `main` ブランチへ移動し、GitHub 上の最新変更を取り込む |
| **新規ブランチ作成** | `git checkout -b <ブランチ名>` | 新しい作業用ブランチを作成し、同時に切り替える |
| **状態の確認** | `git status` | 変更されたファイルやステージング状態を確認する |
| **変更の追加** | `git add .` | すべての変更（作成・更新ファイル）をステージング（コミット準備）する |
| **コミット** | `git commit -m "メッセージ"` | 変更内容をローカルリポジトリに記録する |
| **リモートへ送信** | `git push origin <ブランチ名>` | 変更したブランチを GitHub へ送信し、プルリクエスト（PR）を作れる状態にする |

---

### 2. ブランチの管理・切り替え

| 操作 | コマンド | 説明 |
| :--- | :--- | :--- |
| **ブランチ一覧確認** | `git branch` | ローカルに存在するブランチ一覧を表示する（`*` が現在のブランチ） |
| **ブランチの切り替え** | `git checkout <ブランチ名>` | 指定した既存のブランチへ切り替える |
| **マージ済みブランチ削除** | `git branch -d <ブランチ名>` | マージが完了して不要になったローカルブランチを削除する |
| **強制ブランチ削除** | `git branch -D <ブランチ名>` | 未マージのブランチを強制削除する |

---

### 3. リモート設定・確認

| 操作 | コマンド | 説明 |
| :--- | :--- | :--- |
| **リポジトリの複製** | `git clone <URL>` | GitHub からプロジェクトを初回ダウンロードする |
| **接続先確認** | `git remote -v` | 現在のリポジトリが接続している GitHub の URL を確認する |
| **履歴の確認** | `git log --oneline -n 5` | 直近 5 件のコミット履歴を簡潔に表示する |

---

### 💡 ブランチ命名規則（凡例）

本プロジェクトでは以下のプレフィックス（接頭辞）をつけてブランチを作成します。

- **`feature/`** : 新機能の開発（例: `feature/car-tracking`, `feature/detect-classes`）
- **`docs/`** : ドキュメント・資料の更新（例: `docs/git-cheatsheet`, `docs/update-readme`）
- **`fix/`** : バグやエラーの修正（例: `fix/camera-input-error`）
- **`test/`** : テストや実験的コード（例: `test/sample-video-loader`）
